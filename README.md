# Open Source Intelligence Analytics

## Project Overview
This project analyzes news articles using GDELT GKG data.

## Dataset
- Source: GDELT Global Knowledge Graph (GKG)
- Articles analyzed: 582
- Unique article URLs: 582

## Analysis
- Data quality and missing values
- News tone distribution
- News source comparison
- Organization relationship network

## Key Findings
- 582 articles analyzed.
- No duplicate article URLs found.
- News tone varies across articles and sources.
- Organization extraction reveals connections between articles and named entities.

## Tools
- Python
- Pandas
- Matplotlib
- NetworkX
